# Definition of Done — TrueAlpha v1.0

**Deadline: 2026-08-31.** `v1.0` is tagged only when EVERY box below is checked.

Post-mortem context: previous projects failed on reproducibility and on claiming unverified
results. This file exists so that "done" is defined up front and never renegotiated after
the fact.

## Checklist

- [ ] **Full reproducibility** — a fresh clone plus the README commands regenerates every
      number bit-for-bit. Data is pinned by a SHA-256 manifest, downloaded with absolute
      dates (never `period="2y"`-style relative ranges).
- [ ] **≥ 1 strategy evaluated strictly out-of-sample** — purged/embargoed temporal split
      (`engine.splits`), reported with annualized Sharpe (√365), max drawdown, and
      transaction costs included. In-sample-only numbers are not results.
- [ ] **CI green on main** — ruff, mypy `--strict`, full pytest suite (including the data
      reproducibility test), and the README sync check.
- [ ] **Anti-leakage test in place** (shipped in commit 1) and every new strategy or custom
      split passes through `engine.splits.assert_no_leakage` before being trusted.
- [ ] **README = contract** — every displayed number is generated by
      `scripts/generate_results.py`; all assumptions (costs, slippage, frequency,
      annualization, execution timing) are documented next to the numbers.
- [ ] **Tag `v1.0`** on the exact commit where all of the above holds simultaneously.

## Explicitly NOT done ("done" imposters)

- A strategy with a great in-sample Sharpe and no out-of-sample evaluation.
- A number in the README that no script in the repo reproduces.
- A notebook screenshot presented as evidence.
- Green tests obtained by weakening a guardrail (loosened tolerance, skipped test,
  removed assertion).

## Scope guard

Backtest correctness before any sophistication. No ML until everything above is green
end-to-end.
